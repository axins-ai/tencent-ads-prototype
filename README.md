# 腾讯广告批量计划管理 - 快速原型

> ⚡ 快速原型验证工具 - 用于测试腾讯广告批量投放流程

## 🎯 原型目标

本原型用于快速验证"腾讯广告批量计划管理"的产品想法，支持：
- 快速创建营销单元（按指定配置）
- 批量上传创意（视频+文案+落地页）
- 预览并导出配置

## ✨ 核心功能

### 1️⃣ 新建营销单元
完整实现你提供的配置流程：
- ✅ 营销目的：线索留资
- ✅ 推广产品：运营商产品 → 具体产品
- ✅ 营销载体：页面跳转
- ✅ 转化：数据源上报
- ✅ 投放版位：微信视频号
- ✅ 版位定投：视频号信息流-视频号入口
- ✅ 定向配置：地域/年龄/性别/自定义人群/排除已转化
- ✅ 出价与预算：oCPM/常规投放/出价设定/关闭增强功能
- ✅ 投放设置：日期/时段/日预算

### 2️⃣ 新建创意
- ✅ 创意增强max：关闭
- ✅ 视频上传：支持拖拽上传
- ✅ 文案编辑：每个创意独立文案
- ✅ 落地页配置：卡博士链接+宏参数（{CLICK_ID}等）
- ✅ 品牌形象：视频号
- ✅ 营销组件：浮层卡片
- ✅ 批量创建：一个视频+一个文案=一个创意

### 3️⃣ 预览与提交
- ✅ 完整配置预览
- ✅ JSON数据导出
- ✅ 提交成功提示

## 📦 技术栈

- **框架**：Next.js 14 (App Router)
- **语言**：TypeScript
- **样式**：Tailwind CSS
- **表单**：React Hook Form + Zod
- **图标**：Lucide React

## 🎨 使用流程

### Step 1: 新建营销单元
1. 填写营销单元名称
2. 配置定向（地域、年龄、性别）
3. 设置出价与预算
4. 配置投放时间和日期
5. 点击"下一步"

### Step 2: 新建创意
1. 上传视频（支持多个）
2. 为每个视频编写文案
3. 配置落地页（支持宏参数）
4. 确认共用设置（品牌形象、营销组件）
5. 可添加多个创意
6. 点击"下一步"

### Step 3: 预览并提交
1. 检查营销单元配置
2. 检查所有创意
3. 可导出JSON配置
4. 确认提交

## 📝 原型限制说明

当前为**快速验证原型**，以下功能为模拟：
- ❌ 视频不实际上传到服务器
- ❌ 提交后不调用真实API
- ❌ 数据仅保存在浏览器内存中
- ❌ 无后端数据库

这些限制是为了**快速验证产品想法**，确认需求后再开发生产版本。
